Add the Profile and Connect an agent pages. Profile edits the whole career history, with every resume section, entries and bullets to add, remove and reorder, and saves as you type, logging each save. It imports a PDF, DOCX or JSON Resume file read in the browser, shows what it found, and replaces the profile on confirm. Recent changes come with Undo. Connect an agent shows this server's MCP address and the setup for Claude Code, Codex, Cursor, VS Code, and, in server mode, Claude.ai and ChatGPT.

# Security

Report vulnerabilities and privacy leaks privately. Use GitHub's private vulnerability reporting: open the [Security tab](https://github.com/abijith-suresh/tailory/security) and choose "Report a vulnerability". Do not open a public issue.

In scope: resume content leaving the browser, and any other vulnerability in the site at https://tailory-nine.vercel.app or the code in this repository.

Only the latest deployed version is supported.
